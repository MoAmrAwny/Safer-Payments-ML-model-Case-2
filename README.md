# Safer-Payments-ML-model-Case-2

The goal of this project is to classify bank customers into distinct tiers, such as Platinum, Gold, Silver, and Bronze, based on their attributes. This classification aims to help the bank better understand customer segments and tailor services to meet their needs more effectively. Using Clustering a Unsupervised Learning Technique, we will identify natural groupings within the customer data and assign each customer to the appropriate tier.
